# 🎬 فیلم‌یاب — از خاطره تا عنوان

وب‌اپلیکیشنی که با کمک هوش مصنوعی Gemini، فیلم یا سریال مورد نظرت را پیدا می‌کند:

- **جستجو با داستان:** هرچی از فیلم یادته رو تعریف کن — داستان کامل، یه سکانس، حتی یه دیالوگ.
- **جستجو با ویدیو:** ویدیوی ریلز اینستاگرام یا کلیپ فیلم رو آپلود کن؛ Gemini خودش فریم‌ها را تحلیل می‌کند.
- پشتیبانی از فیلم‌ها و سریال‌های **ایرانی و خارجی**، همه‌ی سال‌ها و کشورها.
- نمایش میزان اطمینان، احتمالات دیگر و لینک مستقیم جستجو در IMDb.

## اجرا روی سیستم (تست محلی)

۱. فایل‌ها را در یک پوشه بگذار.
۲. یک سرور محلی ساده اجرا کن (به‌خاطر مرورگرهای مدرن، باز کردن مستقیم `index.html` ممکن است محدودیت داشته باشد):

```bash
# با پایتون:
python -m http.server 8000

# یا با Node:
npx serve .
```

۳. مرورگر را باز کن: `http://localhost:8000`

## انتشار روی GitHub Pages

۱. یک ریپازیتوری جدید در GitHub بساز (مثلاً `film-yab`).
۲. این ۵ فایل را آپلود کن: `index.html`، `style.css`، `script.js`، `config.js`، `README.md`
۳. از منوی **Settings → Pages** گزینه‌ی **Deploy from a branch** و شاخه‌ی `main` / پوشه‌ی `/ (root)` را انتخاب کن.
۴. بعد از یک دقیقه اپت روی `https://USERNAME.github.io/film-yab/` در دسترس است. 🎉

## نکات امنیتی کلید API

- کلید در `config.js` قرار دارد و سمت مرورگر اجرا می‌شود.
- در [Google AI Studio](https://aistudio.google.com) از بخش تنظیمات کلید، **HTTP referrer restriction** بگذار و دامنه‌ی خودت (`USERNAME.github.io/*` و `localhost`) را اضافه کن.
- کلید همچنین از دکمه‌ی «تنظیمات» داخل خود اپ قابل تغییر است (در localStorage ذخیره می‌شود و بر `config.js` اولویت دارد).

## راهنمای استفاده

| حالت | چه چیزی بدهی | نکته |
|---|---|---|
| داستان | توصیف صحنه/داستان + سال و کشور (اختیاری) | هرچه جزئیات بیشتر، دقت بیشتر |
| ویدیو | فایل ویدیوی ریلز یا کلیپ + کپشن (اختیاری) | تا ۱۵ مگابایت مستقیم؛ بزرگ‌تر خودکار به Files API گوگل آپلود می‌شود |

## تکنولوژی

HTML + CSS + Vanilla JS — بدون فریم‌ورک، بدون بیلد. Gemini API (`gemini-2.5-flash`) برای تحلیل متن و ویدیو.
